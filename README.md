# CSC299 pull request practice

One file per person in `people/`. Add yours with a pull request.

## Steps

1. Fork this repository on GitHub (the **Fork** button, top right).
2. Clone your fork, not this repository:

   ```sh
   git clone https://github.com/<your-username>/<this-repo>.git
   ```

3. Copy `people/example.md` to `people/<your-username>.md` and fill it in. Do not edit any
   other file.
4. Commit and push to your fork:

   ```sh
   git add people/<your-username>.md
   git commit -m "Add <your-username>"
   git push
   ```

5. On GitHub, open your fork and click **Contribute**, then **Open pull request**.

This repository is public. Put nothing in your file that you would not want on a public
web page.
